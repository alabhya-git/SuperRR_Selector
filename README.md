# SupeRR Selector — Rajasthan Royals 2027

A public, read-only dashboard for the SupeRR Selector hackathon submission. It presents the team's ranked batting and bowling shortlists, aggregate evidence, validation limits, and the 2027 auction availability overlay.

The competition data pack and ball-by-ball rows are not included. The interface uses a curated summary export from the analysis workspace.

## Deployment

GitHub Pages serves the static dashboard from this repository. Open `index.html` locally for a preview.

## Sources

- Analysis and rankings: project team's SupeRR Selector model, frozen before the 2026 test.
- Auction status: [IPL 2027 retentions](https://www.iplt20.com/news/article/tata-ipl-2027-player-retentions-announced) and [official release list](https://www.iplt20.com/cms/files/jot2qw8s50z1/3gFAJ4z1USxcXYhaZVl65L/2a463a9c02a5bb7fd12fa3fbe91cc299/TATA_IPL_2027-_Release_Player_List.pdf), checked 18 November 2026.

Released status does not establish auction registration or price. Rankings measure modelled merit, not automatic purchase recommendations.
